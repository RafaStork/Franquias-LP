## Prompt final

Use case: infographic-diagram
Asset type: one transparent PNG 2x2 tree sprite atlas for a flat top-down traffic-diagram website.
Primary request: Exactly four EXTREMELY SIMPLE geometric overhead tree symbols. This is a minimal flat 2D game map, not botanical illustration. Each tree is composed of ONLY 3 to 5 large solid-color geometric shapes total. Absolutely no small details.
Composition: square 1024x1024 canvas. Four isolated trees in equal quadrants centered at (25%,25%), (75%,25%), (25%,75%), (75%,75%). Each tree about 30% canvas width, with generous transparent margin, no touching or overlap between quadrants.
Tree variants: upper left rounded six-lobe outer silhouette with a smaller rounded inner layer and one broad accent; upper right angular eight-point pinwheel conifer with two simple broad inner shapes; lower left asymmetric five-lobe silhouette with two broad inner shapes; lower right oval scalloped crown with two large overlapping internal shapes. These are abstract map symbols made from a handful of bold shapes.
Style: very simple flat vector-like illustration rasterized to PNG. Smooth clean edges, flat solid fills. Readable at 40–100px wide beside an orange 2D truck. Orthographic directly overhead.
Color palette: ONLY #4f7747, #83a878, #1f331b, #628852. Use darkest green sparingly as one large internal region, never an outline.
Background: genuinely transparent alpha channel, including all margins. No white background, no checkerboard baked into pixels.
Avoid: leaves, leaf marks, foliage textures, grain, stippling, hatching, tiny details, branches, trunks, realism, botanical drawing, 3D, isometric, perspective, lighting, shadows, gradients, ground, text, labels, numbers, black outlines, decorative objects. Only four clean minimal tree sprites.
